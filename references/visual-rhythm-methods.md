# 画面节奏的字幕与操作规则

本页保留字幕、步骤揭示和鼠标聚焦的状态要求；具体实现服从本项目所选渲染器。DOM字幕组件不等于默认Remotion接入。原声、场景、字幕共用最终音频时钟，完成态与实际导出检查均须落实。

## V24 关键词与单字字号层级

- **用途：**把句子的重音直接做成视觉重音。
- **操作：**将重点词从普通字幕中拆成独立文字对象，增大字号或改变位置；与剩余文字保持可理解的阅读关系。配镜头强调时分别控制两类对象。同一句字幕内的放大按下方自然衔接规则执行。
- **行内字幕的自然衔接（2026-10-15 用户更新）：**每条字幕先以普通字号、自然字距完整显示；重点词初始与邻字同尺度，不提前占用放大后的宽度，不插入空格或透明占位。到重点词的真实发声锚点，再开始缩放、变色、变形或重音动作；根据重点词当前可见宽度的增量，让相邻文字以同一动画进度平滑让位，保持阅读顺序和整句对齐，居中字幕的句子中心保持稳定。完成后保持变色、放大／变形后的强调态，直到整句字幕退出，不得回到原黑色、原字号或原形态。下一条字幕重新建立自己的普通初始态。本条覆盖旧的“可平滑恢复普通态”分支。
- **可调与前提：**此为可见做法，非作者单独命名的预设。可从普通字号的约 1.3–1.8 倍试起，依真实语气和版面调整。
- **适用范围：**自然衔接规则针对同一句内的重点词/单字强调；独立标题、单独大字和逐条标签仍按其对应方法设计入场。字号、倍率、持续时间与曲线随项目调整，不把一次成片的数值当作固定规范；本条修正不宣称来自参考作者展示的工程参数。
- **检查：**检查自然初始态、发声锚点前、放大／变形中、完成态、句末最后可见帧、字幕退出与下一条初始态；按顺序播放和随机 seek 都应一致。未到重点词时没有异常空槽或提前错行；动作中邻字不跳位、重叠或被裁；没增删原声意思，读序清楚，大字不盖住眼睛、手中产品或必要证据。抽帧核对这些状态后，再正常速度查看衔接。

## V30 全屏步骤文字蒙版

- **来源：**2026-10-15 本用户明确授权的可执行方法，见授权记录：2026-10-15用户明确要求；不是首批作者展示的技法，当前没有该作者的视频证据。
- **用途：**口播中存在明确顺序时，让观众先知道当前是第几步、要做什么，再回到对应证据或操作。
- **操作：**核对真实步骤与顺序；在步骤转换锚点，用覆盖主内容区的文字蒙版／全屏标题表现“序号＋动作短标题”，背景压暗或临时被母版底色覆盖。让新步骤成为唯一焦点，完成态停留到可读，再切回与本步对应的实操／资料；如需保留旁栏，其信息不能与标题争抢。
- **可调与前提：**原声或已确认结构确实有步骤，不为零散观点强行编号。字体、色板、覆盖范围、停留依调用方母版与读字量决定；全屏文字蒙版不等于把全部字幕逐字塞满全屏，也不是持续遮住操作。标题和口播同步，不提前透露未讲的步骤。
- **检查：**序号连续、步骤名准确；手机端大字可读，没有多余注释、互相遮挡或无效留白；转出后操作、字幕、旁栏状态正确。

## V31 真实鼠标同位置聚焦

- **来源：**2026-10-15 本用户明确授权的可执行方法，见授权记录：2026-10-15用户明确要求；不宣称是首批参考作者的原始效果。
- **用途：**操作录屏中让观众跟着真实鼠标／当前操作目标找到视觉重心。
- **操作：**按源片坐标采集或人工核对光标、控件和实际动作；底层保留完整全景，在当前目标原位置用同帧同步副本与蒙版做局部放大，按需要保亮并轻压暗外围。焦点只在真实目标转换时平滑迁移，不对鼠标每次抖动逐帧追赶；操作落定后停稳，说明结束再平滑恢复全景。不能为聚焦把全局界面裁掉。
- **可调与前提：**记录源尺寸、裁切、缩放和时间映射，坐标先转换到成片内容区再应用。目标是菜单或输入框时优先跟控件稳定位置；光标消失、发生切镜或无可靠坐标时退回全景，不猜测点击。不另开固定角落或并排的重复放大界面；为实现同位置蒙版而使用同步副本是允许的，副本与全景必须同源同钟。
- **检查：**聚焦中心落在实际目标上，不错追经过的无关位置；点击、文字和来源身份可见；没有伪造点击、轨迹或结果。窗口变形／剪切后重新核对坐标，退场不残留暗层。
